# Socralearner — 데모 저장소

> ## ⚠️ 이 저장소는 **미리보기용 데모**입니다
>
> `daily/`의 세션 기록과 `mastery.md`의 이해도는 **실제로 일어난 학습이 아니라 예시**입니다
> (노트 frontmatter의 `tags:`에 `demo` 표시). Topdown 화면이 채워졌을 때 어떻게 보이는지를
> 보여주려고 딥러닝 기초 주제로 만들었습니다.
>
> **파일럿 참가자의 학습 증거로 세지 않습니다.** 실제 검증 기록은 Topdown의
> `docs/experiments/proof-log.md`에만 있습니다.
>
> 👉 **화면으로 보기** — Topdown에서 이 저장소를 열면 지식 그래프 · 🚧 막힌 길목 · 다음 행동이 나옵니다.
>
> 내 저장소를 만들려면 [Socralearner 템플릿](https://github.com/youjhun/Socralearner)의 `SETUP.md`를 보세요.

---

> **AI 시대에 할 수 있는 진짜 좋은 공부.**
> AI가 답을 떠먹여주는 대신 **내가 먼저 설명하게** 하고, 그 과정을 **내 GitHub에 자동으로 쌓아** 주는 학습 시스템.

AI한테 물으면 그 순간엔 알겠는데 다음 날 안 남죠. **소비했지 생산하지 않았기 때문**입니다.
Socralearner는 매 세션 **내가 먼저 설명하고 → AI가 약한 곳을 짚고 → 그 기록이 남아 다음 세션의 출발점**이 되게 만듭니다.

---

> ⏱️ **하루 15분~1시간.** 계획을 짜는 도구가 아니라 **오늘 실제로 배우는** 도구입니다.

## 3줄 요약

1. **탑다운** — 목표를 넣으면 거기 도달할 학습 경로를 먼저 세운다. 헤매지 않는다.
2. **소크라테스** — AI가 먼저 답하지 않는다. 내가 설명하고, AI가 반박한다.
3. **자동 기록** — 세션이 끝나면 내 GitHub에 노트·이해도·다음 복습이 **자동으로** 쌓인다.

## 무엇이 남는가

```
내 GitHub repo
├── STATUS.md     지금 뭘 공부 중이고, 뭐가 약하고, 다음에 뭘 복습할지
├── daily/        매 세션의 기록 (내가 한 말 그대로 보존)
├── mastery.md    개념별 이해도 — "암기" vs "설명가능"
├── papers/       내 연구 주제의 새 논문 (매주 자동 수집)
└── concepts.json 개념 지도 (자동 생성) — 앱에서 그래프로 볼 수 있다
```

## 그래프로 보기 (선택)

세션을 몇 번 기록하면 `concepts.json`이 자동으로 만들어집니다. **Topdown 앱의
`/learning-repo`** 에 내 저장소 이름(`myname/my-learning`)만 넣으면:

- 개념 그래프 상태 (설명가능 / 암기 / 미학습 분포)
- 🚧 **막힌 길목** — 아직 설명 못 하는데 다른 개념을 막고 있는 것

을 볼 수 있습니다. 공개 저장소면 로그인 없이 읽기만 합니다. 앱을 안 써도 공부는
그대로 되고, 기록은 언제나 내 GitHub에 남습니다.

**핵심은 `mastery.md`입니다.** 답을 아는 것(`암기`)과 스스로 설명할 수 있는 것(`설명가능`)을 구분해 기록합니다. `설명가능`은 **AI의 반박을 통과했을 때만** 올라갑니다. 이게 "진짜 공부했다"의 증거입니다.

## 시작하기

```
오늘 세션 시작
```

## 어떤 주제든 됩니다

반도체 소자, 신경공학, 논문 재현, 선형대수, 경제학 — 분야를 가리지 않습니다.
목표를 한 줄로 말하면 AI가 그 목표에 맞는 학습 경로를 **가설로** 제안하고, 배우면서 함께 고쳐 나갑니다.

## 어떻게 돌아가나 (구조)

```
"오늘 세션 시작"
      ↓
AI가 내 STATUS.md를 읽음  ──→  세션 진행 (예측 → 교정 → 퀴즈)
      ↓
AI가 GitHub Issue에 평문으로 기록
      ↓
자동화(CI)가 파일로 만들어 커밋  ──→  daily/ · STATUS.md · mastery.md 갱신
```

> AI가 파일을 직접 쓰지 않는 이유: GitHub 파일 API는 본문 전체를 인코딩해 보내야 해서, 노트가 길어지면 실패합니다. 그러면 AI가 살아남으려고 **기록을 3줄로 줄여버립니다**(실제로 겪은 문제). 그래서 AI는 평문만 쓰고, 파일은 자동화가 만듭니다 — **길이 때문에 기록이 사라지지 않습니다.**

---

## 한 가지 약속

**AI가 나 대신 공부하지 않는다.** 내가 공부하고, AI는 내 이해의 약한 곳을 짚고, 시스템이 그 과정을 쌓는다.
남는 것은 정답이 아니라 **나의 이해**다.
