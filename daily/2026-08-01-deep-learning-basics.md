# 딥러닝 기초 테스트 세션

## 목표
- 배포 테스트를 위해 딥러닝 기초 개념을 다룬 가상 학습 세션 기록을 생성한다.

## 예측 — 내가 먼저 답한 것
- "딥러닝은 데이터에서 패턴을 찾아서 입력을 출력으로 바꾸는 여러 층의 신경망이라고 생각한다."
- "역전파는 틀린 정도를 뒤에서부터 전달하면서 각 가중치를 얼마나 바꿀지 계산하는 과정인 것 같다."

## 오늘 직접 학습한 지식
1. 신경망은 입력값에 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 통과시키는 계산을 여러 층으로 쌓은 모델이다.
2. 손실 함수는 모델의 예측과 정답 사이의 차이를 하나의 수치로 나타낸다.
3. 경사하강법은 손실을 줄이는 방향으로 가중치를 조금씩 갱신하는 방법이다.
4. 역전파는 연쇄법칙을 이용해 각 가중치가 손실에 미친 영향을 뒤에서부터 계산한다.

## 교정 및 보완
- 역전파가 오차 자체를 그대로 전달하는 과정이라고 보면 부정확하다. 실제로는 각 파라미터에 대한 손실의 기울기를 연쇄법칙으로 계산한다.
- 층이 많다고 자동으로 좋은 모델이 되는 것은 아니다. 데이터, 최적화, 과적합 제어가 함께 중요하다.
- 활성화 함수가 없으면 여러 선형층을 쌓아도 전체는 하나의 선형 변환과 같아진다.

## 퀴즈
- Q1: 활성화 함수가 필요한 이유는 무엇인가? / 내 답: 여러 층을 쌓았을 때 비선형 관계를 표현하기 위해서다. / 채점: 정답
- Q2: 역전파와 경사하강법의 차이는 무엇인가? / 내 답: 역전파는 기울기를 계산하고, 경사하강법은 그 기울기로 가중치를 갱신한다. / 채점: 정답

## 취약 영역
- 연쇄법칙이 실제 계산 그래프에서 어떻게 적용되는지
- 과적합과 일반화의 차이를 예시로 설명하는 것

## 다음 복습 질문
1. 활성화 함수가 없으면 깊은 신경망이 왜 하나의 선형 변환과 같아지는가?
2. 역전파와 경사하강법은 각각 무엇을 담당하는가?

## 개념 지도
### 수학 기초
- 선형대수
- 미분
- 연쇄법칙
- 선형변환 ← 선형대수

### 딥러닝
- 딥러닝 ← 선형대수, 미분
- 신경망 ← 딥러닝, 선형변환, 활성화 함수
- 활성화 함수
- 순전파 ← 신경망

### 최적화
- 손실 함수 ← 순전파
- 역전파 ← 손실 함수, 미분, 연쇄법칙
- 경사하강법 ← 역전파
- 가중치 업데이트 ← 경사하강법

### 일반화·검증
- 데이터셋
- 과적합 ← 신경망, 데이터셋
- 일반화 ← 과적합
