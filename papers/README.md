# 📬 papers/ — 논문 인박스

`topics.yaml`에 적어 둔 연구 주제로 **매주 자동 수집된 새 논문**이 여기 쌓인다.

| 파일 | 무엇 |
|---|---|
| `inbox.md` | 이번 주 새 논문 목록 (매주 덮어씀) |
| `seen.json` | 이미 본 논문 기록 — 같은 논문이 다시 안 뜨게 (자동) |

**쓰는 법**: 학습 세션에서 *"이번 주 새 논문 같이 보자"* 라고 하면 러너가 여기서 골라 준다.
다 읽지 말 것 — 제목·초록만 훑고 **한 편만 골라** 깊게 보는 편이 낫다.

**지금 당장 돌려보려면**: repo → Actions → **paper-scan** → Run workflow
