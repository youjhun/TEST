# 토익 프리셋 — 시험 트랙용 Socralearner

> **시험 공부는 개념 공부와 축이 다르다.** 전공은 `설명가능`(스스로 유도)이 목표지만,
> 시험은 **시간 안에 정확히 푸는 것**이 목표다. 그래서 같은 엔진을 쓰되 **의미를 바꿔** 쓴다.

## 왜 별도 repo인가

전공 트랙과 **한 repo에 섞지 않는다.** 섞으면 개념 그래프가 오염된다 —
토익 문법 노드가 딥러닝 그래프에 끼어들어 **막힌 길목 계산이 망가진다.**
repo를 나누면 각자 깨끗한 그래프를 갖고, 진도도 따로 보인다.

> 전공용 repo 하나 + 시험용 repo 하나. 세팅은 똑같이 [`SETUP.md`](../../SETUP.md)를 따르고,
> 만든 뒤 이 폴더의 `STATUS.md`·`mastery.md`로 덮어쓰면 된다.

## 쓰는 법 (3분)

1. [`SETUP.md`](../../SETUP.md)대로 **두 번째 학습 repo**를 만든다 (예: `my-toeic`).
2. 이 폴더의 **`STATUS.md`**·**`mastery.md`** 를 그 repo 루트에 덮어쓴다.
3. Custom GPT 지침 맨 아래에 **[`runner-addendum.md`](./runner-addendum.md)** 의 회색 박스를 붙여넣는다.
   (전공용 GPT와 따로 만들거나, 같은 GPT에 두 repo를 번갈아 말해줘도 된다.)
4. `topics.yaml`은 **비워 둔다** — 논문 수집은 시험 공부에 필요 없다.

## 무엇이 달라지나 (엔진은 그대로)

CI·스크립트는 **한 줄도 바뀌지 않는다.** 같은 표, 같은 헤딩, 같은 파이프라인 — 담기는 것만 다르다.

| 자리 | 전공 트랙 | **시험 트랙** |
|---|---|---|
| 개념 | 학문 개념 (푸리에 변환) | **오답 유형** (Part5 시제 일치) |
| `암기` | 답은 아는데 유도 못 함 | **규칙은 아는데 실전에서 틀림** |
| `설명가능` | 스스로 유도하고 반박 통과 | **왜 그 답인지 설명하고 안정적으로 맞힘** |
| 증거 | 세션 링크 | 세션 링크 (그 오답을 다룬 날) |
| 개념 지도 | 선수 개념 | **문법 위계** (`Part5 시제 일치 ← 동사 시제 기본`) |
| 세션 재료 | 논문·강의 | **오늘 틀린 문제 2~3개** |

문법에도 위계가 있으므로 **막힌 길목이 그대로 작동한다** — "이 규칙을 모르니 이 유형들이 계속 막힌다"가 보인다.

## 원칙 하나

**문제풀이 자체를 이 시스템에 넣지 않는다.** 문제는 하던 대로 풀고(책·앱·모의고사),
시스템에는 **틀린 것과 그 이유만** 가져온다. 그래야 공부를 방해하지 않으면서 오답 패턴이 쌓인다.

찍어서 맞힌 문제는 **맞힌 게 아니다** — 그것도 가져온다.
